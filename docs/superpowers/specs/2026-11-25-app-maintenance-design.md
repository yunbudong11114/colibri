# App 菜单、语音状态、包体与职责整理

## 目标与范围

沿用共享 Rust 核心和掌机薄界面。同步当前上下文策略的菜单，离线转写增加轻量动效，暂不释出 API 语音，整理近期上下文和界面代码，并精简发布负载。保留用户配置和现有界面色彩、字体、布局。

用户最新授权覆盖此前暂不测试的限制：完成修改后整体编译、测试、打包、部署到已连接掌机。

## 菜单和配置

菜单保留 MCP 与技能、设置、快捷键、退出，新增直接操作“压缩上下文”和“清理屏幕”，调用现有共享命令与清屏协议。清屏不删除 transcript，不清除模型上下文。自动上下文容量、缓存快照、恢复机制不增加设置。可选内存预算 0 在列表中显示“未设置”，编辑说明明确单位 MiB。

语音设置分类整个隐藏。Rust 公开设置列表及保存白名单同时移除 speech 字段，旧配置不触发在线回退。发布掌机 Recording 只选离线后端，模型不存在就明确报错，绝不上传。暂未释出的在线实现移到独立模块，通过默认关闭的 Cargo feature `api-speech` 保留，正常发行不编译。App Builder 商店说明明确离线语音。

## 动效

输入框同一位置承载录音、思考、离线转写状态。转写显示“正在转写”，三个等大圆点按顺序明暗变化，固定宽度，不虚构百分比。共用现有定时刷新和对象，不新增线程和图片资源。状态切换后第一帧立即更新，布局按输入框字体测量，圆点垂直居中。

## 职责整理

界面设置标签、分类、菜单操作独立为 menu.hpp，由声明的数据驱动菜单分派，去除位置相关的操作分支。输入框动效独立为 composer_activity.hpp，界面只负责状态选择和应用布局。

Rust 会话上下文、历史检查点、预算和压缩方法移入 session/context.rs 子模块，保留 AgentSession 所有权与既有公有接口，执行主循环不掺杂实现细节。在线转写与离线选择隔离，默认构建没有在线语音代码。

## 包体

保持 Rust 已有 LTO、单 codegen unit、strip、panic abort，优化等级设为 s。C/C++ Release 启用尺寸优化、函数/数据分段及链接垃圾回收，使用工具链可用的 IPO。安装只放实际使用的程序、字库、词库、许可证，移除词库生成器部署。离线语音 payload 限定已选的一套模型及实际依赖，排除缓存、录音和调试符号，防止旧模型重复打包。禁止打入用户配置、凭据、会话、Memory 和技能。

## 验证交付

检查既有单测与集成测试，补充隐藏语音设置、离线选择、菜单映射、动效状态和历史恢复的必要回归测试。完成 native Rust 测试、ARM64 Release 编译、界面构建和 deb 检查后部署。备份当前安装包（仅程序），保留设备用户数据，记录升级前后包体与程序文件尺寸，并真机检查转写动效及菜单。无法完成的部分必须明确说明，不声称未经执行的验证通过。

回归补充：FakeModel 仅按当前真实用户轮次读取工具结果，跳过 runtime-context 提醒，避免恢复旧工具结果后污染本轮假模型行为。插入指令测试按固定时间包装后的原始用户文本核对。

结构整理已落到 session/context.rs、cardputer/voice/api.rs、menu.hpp、composer_activity.hpp 与 cmake/offline-speech.cmake。此次限于上下文、语音、菜单和动效职责，main.cpp 的页面、聊天渲染、输入控制仍在同一 View 中，没有声称完成全面解耦。

验证：212 项 Rust 测试最终全部通过，另通过 C++ 菜单与动效组件测试、桌面 Release 构建、ARM64 Release 构建、可选 api-speech 编译检查、包清单及依赖检查。过程中修正旧测试的时间包装断言与 FakeModel 读取旧轮次工具结果的问题。一次并行元数据刷新测试出现瞬时请求计数失败，单项复测和最终串行完整测试均通过。

## 补充：压缩过程动效

压缩时输入框显示“压缩上下文”，复用现有三点明暗动画与固定位置。菜单手动压缩、输入 /compact、自动预算压缩与溢出压缩均覆盖。Rust session 增加独立的瞬时 activity 回调，通过掌机 activity 事件传递，不写入聊天与 transcript，不混用 status 消息。自动压缩完成后恢复“思考中”，手动命令完成时由 reply 清除状态。回调不增加配置项，CLI/Gateway 没有订阅时不产生影响。界面收到事件只更新忙碌状态和输入框，不跳动滚动位置。发布 0.1.74，完成回归、编译、打包和真机验证后部署。

## 动效统一（用户最终选择 A）

思考、离线转写和上下文压缩统一为三点依次跳动：每 180ms 切换活跃圆点，活跃点向上偏移 3px，其余点保持基线，所有点不透明度一致。三种状态共用同一帧计算，不保留明暗分支。录音继续使用声波，位置、颜色、尺寸与既有设计保持一致。更新组件回归断言，发布 0.1.75 并部署，保留用户正在运行的应用与草稿。

0.1.75 验证：三种处理状态共用同一三点跳动计算，ARM64 组件回归覆盖每个状态的三个相位、固定不透明度和唯一上移圆点。桌面及 ARM64 Release 构建通过。Rust 核心未修改，沿用 0.1.74 已通过的 214 项 Rust 测试结果。间距继续按当前字体测量文字后留一汉字宽，圆点 3×3px、中心间距 5px、上移 3px。
