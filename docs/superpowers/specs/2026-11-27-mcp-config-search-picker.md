# MCP 独立配置与搜索引擎选择

MCP 使用主配置旁的 mcp.json，内容为现有服务器数组。[mcp].config_path 可覆盖位置，相对路径以 config.toml 所在目录为基准。旧 servers 一次迁移，先原子保存权限为 0600 的 JSON，再移除 TOML 中的旧项。目标文件已存在时以其为准，避免覆盖独立配置。App、REPL、Gateway 在下一轮检查两个文件。

掌机配置菜单移除 MCP JSON 编辑，插件下的 MCP 查看入口保留。搜索引擎采用两项列表，显示当前值，Enter 保存，Esc 返回。切换引擎时清除另一服务商的凭据并重置地址，避免发送给错误的后端。

本次打包使用 1.0.1，便于区分已部署的 1.0.0。同步更新掌机 Debian 包和 Mac CLI，验证原配置与网关连接。
