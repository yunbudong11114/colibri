# 设置菜单与统一模型配置引导（0.3.2）

## 目标与最终层级

首页入口及根页标题均为“设置”。一级顺序严格为：任务进度、配置、帮助、插件、退出 Colibri。

- 任务进度：只读任务与后台作业状态，Enter 刷新。
- 配置：模型、图片理解、搜索、历史与上下文、记忆、MCP 配置；现有表单/记忆编辑逻辑保留。
- 帮助：快捷键、斜杠命令两个二级入口，分别打开只读文本页。仅说明掌机实际支持的 /clear、/compact，不混入终端专属命令。
- 插件：MCP、技能两类列表，查看名称与说明。
- 退出 Colibri：直接关闭，不经过聊天画面。长按 Esc 1.5 秒也保留。

根页无输入框，使用完整 124px 内容区显示五个一级项目，维持原行高和字体；其余配置列表维持原布局。返回恢复正确父项；帮助文本返回帮助二级列表。退出项目选中时底栏显示 Enter 退出。

彻底删除显示分类、浅色调色分支、dark_ 状态及主题切换重染循环，只保留当前深色配色，不是仅隐藏入口。不改变录音快捷键、中文输入、历史滚动和 /clear 的既有语义。

## 核心检查与入口差异

用户配置读取统一从“未配置真实模型”基线开始；无文件或缺少 [model] 不再隐式使用 fake。模拟模型仅保留显式 provider=fake，程序化测试的 AgentConfig::default 仍作 fake fixture。显式 --config 指向尚未创建的文件，也给出该路径的配置引导；权限与格式错误不吞掉。

Rust model 层统一构造检查，失败提示以“未配置 AI 模型”开头，包含缺少字段、实际配置路径及正确引用路径的 colibri --config PATH configure 命令。现有本地免密服务规则保留；只检查格式/必要字段，不声称联网认证成功。

- CLI ask/REPL 在 ready/thinking/交互提示符前检查。
- 掌机 colibri --repl 同样启动预检并给终端命令，不能展示 GUI 专属按 Enter 提示。
- gateway start 在创建子进程前预检；gateway run 在启动渠道前构建 Agent。后台不等待交互输入。
- App 可进入、查看历史和使用离线配置/插件/任务菜单。GUI 展示层将模型错误映射为短提示：未配置 AI 模型；按 Enter 配置，或设置 → 配置 → 模型。空输入按 Enter 也可直达模型配置，/clear 仍可独立使用。
- help/version/configure/auth 等不依赖模型的操作保持可用。

## 命令行逐步配置

新增 colibri configure，支持既有全局 --config；Mac CLI 与掌机 CLI 复用同一向导。按云端/自定义或本地、API 地址、模型 ID、密钥的顺序填写，最后显示不含密钥的摘要并确认保存。

密钥不回显，普通错误、EOF、Ctrl+C 取消时恢复终端输入状态；输入 :cancel、EOF 或拒绝确认均不写配置。同一端点留空可保留原密钥，- 清空；切换端点不携带旧密钥或原模型 ID。向导仅显示格式检查结果，不发网络认证请求。

保存沿用 settings.lock，持锁后重读文档并保留其他配置及注释。模型段已被其他入口修改时拒绝覆盖。原子写入、权限 0600；不写第二份配置，不保存向导状态，不自动重启运行中的服务。App/终端引导与 README 同步更新。
