# 低资源设备与模块边界优化（0.3.1）

先根据代码证据确定范围，再修改实现。保持完全访问和现有配置、界面风格，不新增设备专属的核心策略配置。

## 发现

- 作业 supervisor 每秒原子写 state，即使安静命令没有任何输出变化，也会 fsync；长任务造成不必要写盘。
- 作业模块把工具入口、状态存储、输出处理和进程生命周期放在一个文件；内部调用先序列化成 JSON 再反序列化（任务页尤为明显）。
- 工具 schema 的前缀指纹每次先构造完整 JSON 字符串再哈希，产生与 schema 大小成正比的临时分配。
- C++ WorkerLink 持续读取直到 EAGAIN，再按行反复 substr/erase，积压时既可能占用无界内存，也会阻塞 UI 一帧；协议解析与进程传输耦合。

## 实现

1. 作业模块拆成 facade、store、output、process 四个职责。共享 Rust 核心依然只依赖标准 OS/运行时路径；掌机页面只依赖类型化只读快照，不直接解析持久化结构。保留兼容的工具 JSON 协议，但内部改用 typed APIs。
2. supervisor 仅在输出计数/截断状态变化且达到写盘间隔时保存中间 metadata；最终状态总是保存。取消仍按 100ms 检查，不降低交互响应。输出读取线程复用缓冲区，避免每个分片分配新的 Vec。
3. 工具前缀指纹通过 serde_json::to_writer 流式写入哈希器，不构造完整字符串；字节内容和现有缓存判定语义保持一致。
4. 提取独立 JsonLineDecoder，单帧最大 1MiB，超限丢弃到换行并报告协议错误后可恢复；不能静默解析残缺内容。每次 receive 最多读取 64KiB，让事件循环继续绘制。按输入分片的换行边界拼接单帧，解析后清空，不使用逐行 substr/erase 搬移积压字符串；UTF-8 分片按原字节拼接后解析。超过单帧上限是传输安全边界，与 Agent 工具权限无关。

## 验证与限制

用行为测试覆盖 IPC 半包/多行/UTF-8/超限恢复、typed 快照与既有协议、流式哈希等价、静默作业不改写中间 state 且取消/完成仍正常。运行完整 Rust 回归与 C++ 组件测试，编译 Mac/ARM64、打包部署；真机验证菜单、任务页、进程恢复和微信网关。保留现有配置与 memory 的摘要校验。

只声称已验证的减少：消除对应临时 JSON 字符串、消除静默作业周期性 metadata 写入、限制 IPC 每次读取和单帧缓存。没有前后 RSS/帧率实测时，不宣称整体内存下降百分比或启动提速。大规模历史零拷贝及整个 GUI 类拆分另需针对性设计，不在本轮机械改写。

回归补充：取消测试暴露了 supervisor 启动交接时的竞态。若状态查询暂时认为进程 interrupted，不能丢弃用户取消请求；对未达终态的作业仍写入取消标记。实际 supervisor 接管状态时明确标记 running，再进入循环消费该标记。取消只交由持有 Child 的进程处理，不盲杀外部 PID。

进一步诊断确认退出交接的 TOCTOU：查询读到旧 running，探测 PID 时 supervisor 已保存终态并退出。因此确认失联前必须重读最新 metadata；若探测没有返回身份但 PID 仍存活，也不能直接报 interrupted。该重读只发生在异常探测路径，不增加正常轮询写盘。
