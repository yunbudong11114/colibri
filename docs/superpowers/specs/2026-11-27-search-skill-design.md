# 百度搜索独立技能

1.0.2 移除掌机搜索配置、内置 web.search、百度及阿里云适配和项目示例中的搜索配置。Rust 与 Python 入口同步。发布包不包含搜索技能。
百度技能作为用户目录里的独立安装，声明 search 和 fetch 两个命令。search 只提供有限条数的标题、链接和摘要。fetch 每次只读取指定公开页面，按当前待核验问题定位片段，限制下载与输出，缓存正文供后续分页。网页内容仅作资料。
部署时将本机原百度密钥转移到技能目录权限为 0600 的独立文件，从主配置移除旧搜索项并保持其余内容。密钥不进入源码、产物、命令参数和测试输出。校验两端版本、技能发现、搜索、正文读取与 Gateway。

独立技能以 web-search 为名。search 当前使用百度，后续可接入其他后端并统一结果字段。fetch 直接读取公开 HTTP(S) 页面，与搜索后端无关。两端原技能目录整体改名，保留密钥和缓存。
